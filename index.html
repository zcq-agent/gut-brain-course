共病不是巧合：流行病学事实

在谈论机制之前，先承认事实的分量 Meta临床

流行病学证据

  • 睡眠×情绪｜抑郁发作期约 90% 患者伴有睡眠症状（入睡困难 / 早醒 / 睡眠破碎）
  • 前瞻｜无抑郁人群中的失眠，使新发抑郁风险约为 2 倍
  • 时间顺序｜失眠常先于抑郁出现；残留失眠是抑郁复燃的最强预测因子之一
  • 肠×情绪｜IBS 患者抑郁/焦虑患病率约为普通人群 2–3 倍，且为双向
  • 结构性提示｜情绪、睡眠、肠道症状两两共病率都显著高于随机 → 提示共享机制
结论
共病是规则，不是例外。需要一个能同时解释两组症状的共同底层。

提醒

  • 教科书常按“抑郁→失眠”单向叙述
  • 但时间顺序数据支持失眠在先居多
  • 双向因果 = 共同底层网络的投影

迷走神经：肠-脑之间的“高速专线”

动物临床综述

一·脑肠轴

菌群代谢物：脑肠轴的“信使分子”

膳食结构 → 菌群功能 → 代谢物谱 → 脑肠信号（可控性最强的环节）综述动物临床

短链脂肪酸 SCFA（乙酸 C2 / 丙酸 C3 / 丁酸 C4）

  • 来源：不可消化膳食纤维的结肠发酵产物
  • 丁酸：结肠细胞主燃料；HDAC 抑制剂（表观遗传调控）；抗炎
  • 受体：GPR41/43（FFAR2/3）分布于免疫与神经细胞
  • 丙酸：维护 BBB 完整性（动物模型）
  • 临床相关：抑郁症状人群产丁酸菌（如 F. prausnitzii）减少（横断面宏基因组，Kim 2025）

色氨酸衍生物与其他

  • 吲哚类：菌群将 Trp 转为吲哚/IPA/IAA → AhR 信号 → 肠屏障与免疫稳态
  • 次级胆汁酸：经 FXR/TGR5 影响代谢与情绪相关通路
  • GABA：乳杆菌/双歧杆菌部分菌株可产 GABA（肠腔局部与迷走信号）
  • 关键观念：菌群主要不是“替我们产神经递质”，而是改写可用的底物与信号环境
膳食是脑肠轴最大的“上游变量”：纤维与发酵食品决定 SCFA 谱；蛋白与色氨酸摄入决定 Trp 底物量；进食时间决定菌群节律（模块二）。这三点都是门诊可处方的生活方式杠杆。

一·脑肠轴

关于 5-羟色胺的三个临床误区

把“肠脑血清素”讲准 综述

1误区 1

“肠道产 90% 的 5-HT，所以肠在给大脑供 5-HT”
✓ 纠正：外周 5-HT 不能穿过 BBB（极性分子、缺乏转运体）。肠源 5-HT 作用于外周受体与迷走信号，不直接“补脑”。

2误区 2

“吃色氨酸/5-HTP 就能提升脑 5-HT”
✓ 纠正：Trp 入脑需与其他大分子中性氨基酸竞争同一转运体（LNAA）；胰岛素刺激的 LNAA 清除、炎症分流都会改变入脑比例。

3误区 3

“菌群与 5-HT 无关”
✓ 纠正：菌群调节肠 TPH1 表达与血浆 Trp 可用性，并通过犬尿氨酸分流间接影响脑 5-HT —— 是间接但真实的调控。

一·脑肠轴

两道屏障，一个故事

肠屏障与血脑屏障是同一炎症通路的上下游 临床动物

第一道：肠屏障（“肠漏”）

  • 结构：紧密连接 claudin / occludin / ZO-1
  • 失效时：LPS 等内毒素易位入血 → TLR4 → 系统性低度炎症
  • 诱因：高脂/低纤饮食、酒精、慢性应激、NSAIDs、菌群失调

第二道：血脑屏障（BBB）

  • 结构：内皮紧密连接（claudin-5 / ZO-1）＋ 周细胞 ＋ 星形胶质细胞足突
  • 失效时：细胞因子与白蛋白进入 CNS → 小胶质细胞激活
  • 临床：青少年 MDD 患者肠屏障与 BBB 通透性标志物同时升高（横断面研究）

保护性因素（证据强度递减）

  • SCFA（丙酸护 BBB，动物）｜丁酸产菌丰富度（人群相关）｜膳食镁（动物：降低 BBB 通透性，Zhu 2018）｜应激管理
  • 注：尚无“增密屏障”的确定性临床干预 —— 目前策略是移除损伤因素 ＋ 支持菌群代谢环境

动物

五·整合

同一网络，两个方向：恶性环 vs 良性环

恶性环（病例的惯性路径）

  • 慢性应激 ＋ 夜间蓝光 ＋ 晚餐过晚 ＋ 低纤维/酒精
  • → 菌群振荡弱化 · 肠屏障渗漏
  • → 皮质醇夜间偏高 ＋ 褪黑素脉冲被压
  • → 睡眠破碎（N3↓）
  • → 炎症↑ ＋ IDO 分流色氨酸
  • → 情绪下坠 ＋ 更严重失眠 →（回到起点）

良性环（干预的复利路径）

  • 固定起床 ＋ 晨光 ＋ 进食窗口 ＋ 纤维/发酵食品
  • → 菌群节律稳固 · 屏障修复
  • → 皮质醇形态正常 ＋ 褪黑素脉冲恢复
  • → 睡眠结构修复（N3↑）
  • → 炎症回落 · 色氨酸回到 5-HT/褪黑素支线
  • → 情绪与睡眠互为杠杆 →（自我强化）
核心命题：干预任一节点都有网络级收益；同时撬动的节点越多，环转得越快 —— 这就是“整合干预”的理论根据。

六·落地

评估路径：三层递进

先结构后实验室，实验室不替代精神科评估 临床

第 1 层｜病史（0 成本，最重要）

  • 睡眠-情绪-胃肠三联问诊（谁先出现？）
  • 作息规律性：工作日 vs 周末睡眠中点漂移 >1h？
  • 应激源盘点（工作/家庭/经济）
  • 物质：咖啡因时点、酒精、夜间屏幕
  • 用药史：抗生素频次、PPI、SSRI

第 2 层｜基础实验室

  • hs-CRP（炎症分层线）
  • HbA1c / 空腹血糖·胰岛素
  • 铁蛋白 ＋ 转铁蛋白饱和度（不宁腿/周期性肢体运动相关）
  • TSH、25(OH)D、B12／叶酸
  • 每个项目都有明确处理路径才开

第 3 层｜进阶功能检测（按需）

  • 4 点唾液皮质醇 / CAR：看形态（方法学敏感）
  • 尿有机酸：色氨酸-犬尿氨酸分支旁证
  • 粪便菌群＋钙卫蛋白：描述性；跨平台一致性差 → 不建议直接“对菌下药”
  • 原则：向患者说明证据等级与局限
红线：中重度抑郁、自杀风险、双相线索、精神病性症状 → 精神科共诊优先，功能医学评估随后跟上。

六·落地

心理益生菌（Psychobiotics）：如何在门诊谈循证

临床动物

证据现状（截至 2026）

  • 人体：小样本 RCT 信号（B. longum 1714、多菌株组合降低皮质醇/改善情绪评分等）
  • 动物：机制强证据 —— L. reuteri（本课两篇文献都在场：HPA＋褪黑素）
  • 缺失：大样本、菌株特异、时间固定给药的人体 RCT

三要素（缺一不可）

  • 菌株：报告到株号（不是“益生菌”三个字）
  • 剂量：CFU 数量级
  • 时点：动物证据强烈提示时间敏感（文献①）

话术示范（对纠结的患者）

“这类干预的证据正在积累，目前定位是配合节律和饮食的辅助。我们用 4 周做客观记录——睡眠日记＋PHQ-9＋（如有）复查 hs-CRP。有改善我们继续，没有就换思路。”
避免：益生菌＋褪黑素＋轻断食同时上 → 无法归因，也无法建立患者信任。
